Pour garantir une immersion totale et une navigation fluide dans l'UFR MIM, cette visite virtuelle adopte le point de vue d'une personne se déplaçant librement dans le bâtiment.

La souris permet d'orienter le regard afin d'explorer les différents espaces de manière naturelle, tandis que les touches [Z][Q][S][D] (ou les flèches directionnelles) servent à se déplacer.

Vous pouvez ainsi parcourir les couloirs, entrer dans les salles, monter ou descendre les escaliers et découvrir l'UFR comme si vous y étiez réellement.
